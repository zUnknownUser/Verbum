# Event catalogue expansion — 2026-10-08

## Delivered scope

Events grows from 4 to 137 canonical entities (133 additions), with 274 English and
Brazilian Portuguese presentations and 171 chapter reading links. Each study has
an episode summary, a separate paragraph of narrative context, sources and existing
people/place connections where the identity is known. Selected Gospel events include
parallel accounts for comparison. References were checked against the local canonical
chapter inventory; no Bible translation text is copied into the catalogue.

The builder reuses the timeline corpus for 86 entries and adds 51 distinct episodes
from `pipeline/sources/events/additions.psv`. The four existing event IDs remain.
Five timeline entries that serve as period/contextual overviews are not automatically
turned into event studies. The timeline keeps its 91 rows; this release does not add
137 more rows to it. The 51 additional catalogue episodes are not yet assigned an
individual timeline position. This is an expanded initial catalogue, not exhaustive
coverage or an assertion of an exact historical chronology.

## Shared identities and publication

Bundle v6 carries bilingual presentations, era classification and explicit mappings
from a timeline row to its canonical event. Migration 0011 stores those mappings in
`timeline_event_catalog`, separately from participants, so subsequent timeline
publication cannot remove them. Its unique constraints prevent duplicate mappings;
publication rejects rebinding, unknown graph IDs, missing timeline rows, mismatched
eras and attempts to overwrite another entity type. `event_eras` retains classification
across the 10 current eras for later navigation improvements; the current catalogue
UI uses alphabetical browsing and search.

The timeline API exposes an optional `discovery.eventEntityId`. Existing entity filters
and name resolution include this identity without duplicating participant IDs. The
apps show “Open event study” for mapped entries and the existing event detail can link
back to its timeline position. Old responses without this field remain supported.

Both apps use the existing bounded catalogue implementation for Events: 30-row pages,
search, an alphabetical index, explicit “Show more”, loading/error/empty states and
existing stale-response/cancellation protection. Chapter links appear before graph
and voice actions on event study pages. No voice/audio generation is invoked by this
work.

Source and regeneration:


The generated bundle is `pipeline/sources/events/catalog.json`. Review is bound to its
hash in `pipeline/review/events-2026-10-08.json`. Reviewer attribution explicitly names
Codex acting under Lucas's delegation; it does not claim independent human or theological
review. Original bilingual notes distinguish narrative observations from interpretation.
Ambiguous Mary, John and Saul names are not automatically assigned graph identities.
